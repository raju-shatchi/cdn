# Shatchi product images

The Range product images are stored in `images/the-range/`.

This collection contains 811 JPEG images covering 125 products. Images use a
2,000 × 2,000 pixel canvas with their original proportions preserved.

Direct image URL format:

`https://raw.githubusercontent.com/raju-shatchi/cdn/main/images/the-range/<filename>.jpg`
